🔑 获取 Access Token OAuth 2.0

使用 Client Credentials 授权模式获取 Token。Token 有效期 15 分钟（900 秒），系统会自动缓存复用。 

POST /v3/token
Authorization: Basic Base64(ClientID:ClientSecret)
Body: grant_type=client_credentials

→ 响应: {"access_token":"eyJ...","expires_in":900}

📦 构建商品 Feed Item Spec 5.0

填写商品信息，系统自动生成符合 Walmart Item Spec 5.0 的 Feed JSON。

优化：标题 + 简述 + 详述 + 五点特征
🤖 AI 优化预览
Walmart 要求 5 条核心卖点，每条会显示为商品页面的 Bullet Point
同一商品的不同颜色/尺码等变体，每个变体是独立 SKU

🔎 目录搜索 POST /v3/items/catalog/search

💡 上架前搜索 Walmart 目录，确认商品是否已存在。如已存在可用 MP_ITEM_MATCH 快速创建 Offer，无需全量上架。

🏭 WFS 仓库存查询 GET /v3/fulfillment/inventory-details

🏭 查询 Walmart 履约中心 (WFS) 的实时库存数据。新版端点 /v3/fulfillment/inventory-details 替代旧版 /v3/fulfillment/inventory（2026 弃用）。

📤 提交商品 Feed POST /v3/feeds

确认 Feed JSON 后提交到 Walmart API。提交成功将返回 feedId。

⚠️请先在「构建商品」步骤生成 Feed JSON

⏳ 轮询 Feed 处理状态 异步

Feed 提交后 Walmart 异步处理。点击查询查看最新状态，或开启自动轮询。

🔍 查询商品发布状态 GET /v3/items

Feed 处理完成后，查询商品是否已成功发布到 Walmart.com。

📊 设置库存 PUT /v3/inventory

⚠️ 新商品在 Walmart 系统中需要约 4 小时生效。Live 模式下过早设置库存会收到 "SKU not found" 错误。

💰 设置价格 PUT /v3/price

通过 Price API 单独管理商品售价。

🎉 完成所有步骤后，商品已在 Walmart.com 上线销售！
⏳ 本服务托管于 Hugging Face 免费空间，长时间无访问会自动休眠，首次打开需 10~20 秒冷启动，请稍候片刻即可正常使用。
